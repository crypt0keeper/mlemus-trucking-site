# M Lemus Trucking Inc. website

Source for https://mlemustrucking.com. Built with Vite, React, TypeScript, and Tailwind.

## Run locally
npm install
npm run dev

## Build
npm run build   # output goes to dist/ (Cloudflare Pages build command / output folder)

## Customer logos
Drop logo files in public/logos/ and add the path in src/components/LogoCarousel.tsx.
